# JobiX — Fix HTML-Only Resume Preview/Export Review Guard

Implement the smallest targeted fix identified by the read-only Resume Layout audit.

## Objective

Ensure that an HTML-only difference between the reviewed Resume Preview and the newly fetched authoritative Resume HTML invalidates the previous review.

When such a difference is detected:
- Refresh the displayed Preview with the latest authoritative content.
- Do not submit a PDF export request on that same tap.
- Require a separate, explicit Export tap after the refreshed Preview is displayed.
