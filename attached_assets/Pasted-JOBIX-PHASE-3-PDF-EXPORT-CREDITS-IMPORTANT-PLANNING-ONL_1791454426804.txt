==================================================
3. CREDIT RULES — MUST PRESERVE EXACTLY
==================================================

PDF export:

- NEW PDF export = 2 Credits
- Existing valid PDF download = 0 Credits
- Failed export = no permanent Credit loss
- Reservation happens before the chargeable operation
- Consume only after successful PDF completion
- Release reservation after confirmed failure
- Server is authoritative
- Client cannot grant or consume Credits directly
- Duplicate requests must not double-charge
- Retry/recovery must not double-charge
- An existing valid completed export must be downloadable without another 2-Credit charge

Other existing Credit rules must remain unchanged:

- Signup = +5 Credits
- Professional Email = 1 Credit per successful use
- Cover Letter = 1 Credit per NEW PDF export
- Profile 2 = 10 Credits once
- Profile 3 = 20 Credits once
- Daily Reward = +2 Credits

Do not implement or change subscriptions, billing, Premium pricing, or payment flows.

==================================================
