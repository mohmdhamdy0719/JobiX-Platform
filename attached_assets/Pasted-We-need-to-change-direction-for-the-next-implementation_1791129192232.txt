1. Career Profile creation must be one continuous guided journey

Instead, create a guided profile-building journey.
For example:
- Step 1/6 — Personal Information
- Step 2/6 — Professional Summary
- Step 3/6 — Work Experience
- Step 4/6 — Education / Projects / Career Evidence
- Step 5/6 — Skills & Languages
- Step 6/6 — Review / Resume Configuration
The exact number of steps can be adjusted if necessary to match the approved product requirements, but the experience must feel like one continuous profile-building flow.
The user should:
1. Enter information.
2. Tap Continue.
3. Move to the next section.
4. See clear progress such as 2 / 6.
5. Be able to go back and edit previous steps.
6. Keep all entered data safely as a draft.
7. Eventually reach a review/preview stage.
8. Then preview and export the CV.
Do NOT make the user manually press "Save" after every section as the primary journey.
Important distinction
"Save" should not be the main UX concept for the guided builder.
Use:
Continue → Continue → Continue → Review → Preview → Export
rather than:
Save → Career Page → Edit Summary → Save → Edit Experience → Save...
Data should still be persisted safely in the background/server/local draft architecture, but this should be invisible to the user unless necessary.
