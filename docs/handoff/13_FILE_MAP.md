## Documents and preserved experiments

- Root `PROJECT_HANDOFF.md` and `docs/handoff/`: current migration entry points.
- `docs/handoff/history/`: preserved ignored task-plan sources, historical only.
- `mobile/jobix/README.md`, `FIRST_SLICE.md`, `VERIFICATION.md`,
  `DESIGN_SYSTEM.md`, `VISUAL_REDESIGN_AUDIT.md`, `VISUAL_REDESIGN_REPORT.md`:
  setup and dated implementation/design evidence. Earlier scope text is historical.
- `attached_assets/`: original Architecture V1/V2, Constitution, Product Design,
  DESIGN, owner briefs, screenshots and HTML reference prototypes. Leave original
  paths intact; prototypes are not functioning current product UI.
- Relevant HTML families in `attached_assets/` include splash/onboarding,
  research, Auth, all builder steps, Career, AI-proposal and Resume/export
  references. The design files intentionally contain illustrative content; never
  copy it into a user's Profile or treat it as real AI/PDF output.
- `deliverables/`: generated review/verification HTML and development build
  packages. APK/ZIP release artifacts use Git LFS; a pointer alone is not a
  downloadable binary. Files are preserved at their existing paths.
- `.agents/memory/`: tracked project constraints/lessons, not product architecture
  or a complete task transcript.
- `.local/tasks/`: ignored workspace-only plans. Tracked historical copies and
  task summaries were added because clones do not include this directory.
