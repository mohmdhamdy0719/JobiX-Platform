VISUAL DIRECTION

Create a polished, modern, professional career-product UI for Jobix.

Design language:
- Clean and typography-led.
- Premium but not flashy.
- Professional career/productivity feel.
- Neutral/light surfaces.
- Jobix brand blue for primary actions and important accents.
- Deep navy for major headings.
- Fine borders.
- Subtle or minimal shadows.
- Generous but controlled whitespace.
- Strong visual hierarchy.
- Compact, clean selection rows/cards.
- Consistent 8pt-style spacing system.
- Comfortable touch targets.
- No oversized decorative illustrations unless they genuinely improve the UX.
- No generic AI-app visual style.
- No excessive gradients.
- No excessive rounded cards everywhere.
- Avoid empty screens with huge unused areas.
- Avoid unnecessary visual noise.

The design should look like a serious professional career platform, not a template/demo app.

TYPOGRAPHY

Typography is a first-class part of the design.

English:
- Use Inter as the primary English UI font.
- It is already approved/bundled.

Arabic:
- Use Noto Sans Arabic as the primary Arabic UI font.
- Obtain/use the openly licensed Noto Sans Arabic font.
- Bundle it properly with the Flutter application.
- Do not rely on Android platform fallback for production Arabic UI.

The Arabic typography must be intentionally designed, not treated as a translated English layout.

For both languages:
- prioritize readability
- use appropriate font weights
- avoid overly small text
- avoid excessive letter spacing
- maintain clear hierarchy between display/title/body/caption text
- ensure Arabic glyphs and line heights look professional
- verify mixed Arabic/English text
- verify numbers, email addresses and technical terms
- support proper RTL/LTR behavior

RESUME TYPOGRAPHY

Resume typography is especially important.

The Resume Builder and generated CV must use professional, highly readable fonts suitable for an actual job application.

English resume:
- Inter is the default choice unless a more appropriate bundled/approved resume font is required.

Arabic resume:
- Noto Sans Arabic is the default choice.

Do NOT use decorative, playful, overly stylized, condensed, or difficult-to-read fonts.

The resume must prioritize:
1. readability
2. ATS-friendly text extraction
3. professional appearance
4. clear hierarchy
5. good density
6. consistent rendering in PDF

The resume must remain selectable/searchable text, not an image.

Do not sacrifice readability just to make the resume fit on one page.
